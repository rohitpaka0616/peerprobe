A PEER TESTING WORKSPACE

Fresh eyes.
Better builds.

One student publishes a task against an exact preview. Another student tests that build, reports what broke, and later checks the fix. The original result stays attached to the version that was tested.

02
Test and report

Jamie claims the task, marks each step, and files an issue that stays private to the two of them.

03
Retest the next build

A newer build gets its own attempt. The first session remains pinned to the original version.
